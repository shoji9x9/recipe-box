# 画面の見た目の決まり

画面の文字・色などの使い分けを書く。値そのもの（色・余白・幅）は `apps/recipe-box-rs/public/assets/style.css` の先頭の変数にあり、色の差（コントラスト）の理由も、その変数のコメントに書いてある。
画面に何を出すか（文言・動き）は [spec.md](spec.md) の「画面」に従う。ここには、どう見せるかだけを書く。

## 文字

役割ごとに、大きさと色を次のようにそろえる。新しい文を足すときは、どの役割かを決めてから、その見た目にする。

| 役割 | 例 | 見た目 |
| --- | --- | --- |
| 画面の見出し | `h1`（「ワークスペース」など） | 28px（狭い画面は 22px）・太字・濃い色（`--ink`） |
| 画面の主な説明 | 「はじめる」画面の説明、ワークスペースが無いときの 14 日の説明 | 16px・本文の色（`--body`。`p` の既定） |
| 欄の名前 | `label`（「料理名（必須・100 文字まで）」など） | 14px・太字・濃い色（`--ink`） |
| 補足 | 欄や操作に添える注意（`.note`。Cookie を消すと ID を忘れること、写真の位置情報など） | 14px・灰色（`--muted`）・標準の太さ |
| 共有のデモの帯 | 画面の上の帯の文 | 14px |
| ボタン | `button` | 16px |
| 文字だけのボタン | `button.text`（一覧の「削除」など） | 14px |

- 欄の名前と補足は同じ 14px なので、欄の名前は太字と濃い色にして、灰色で標準の太さの補足と見分ける。
- 欄に何を入れるか・欄の値をどう扱うかの補足は、欄の名前と欄の間に置き（`label + .note`）、`aria-describedby` で欄に結び付ける（例: ID の欄の上の、Cookie を消すと ID を忘れること）。
- 欄ではなく、画面やデータ全体についての補足は、関係する欄や操作の後に置き、欄には結び付けない（例: ID の欄の下の、14 日で消えること）。
- 同じ内容の文は、どの画面でも同じ役割にする。ただし、その画面の主な説明として出すときと、補足として出すときは、役割が違ってよい（例: 14 日で消えることは、作る前の説明では「主な説明」、自分の一覧の下や ID の欄の下では「補足」）。

## 文の折り返し

- 帯などの短い知らせは、文のまとまりごとに `p` を分け、広い画面では途中で折り返さないようにする（例: デモの帯は「書かないでください」までの注意と、元に戻る時刻を分ける）。
- 帯の文は幅 720px までに収めるので、1 つの `p` は 14px で 45 文字ほどまでにする。超えるときは、まとまりを分ける。文言を変えるときは、広い画面で折り返さないことを目で確かめる。
- 狭い画面で折り返すときは、日本語の文節の切れ目で折り返す（`word-break: auto-phrase`。対応していないブラウザは、ふつうの折り返し）。

## ID の表示

- ワークスペースの ID は、出す欄も入れる欄も、等幅の字（`--font-mono`）にする（class `workspace-id`）。16 進数の文字を読み比べやすくするため。
